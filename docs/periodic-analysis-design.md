# 定期調査分析設計

## 範囲

本設計は、`調査データ`を読取専用で検索し、一覧表示用の年度グループと前回差を構築する仕様である。UI、Google Sheets本番接続、気象取得、収穫時予測は含まない。

## 検索

- 必須条件: 品種カテゴリー、`調査基準月`の月、`調査区分`（前半／後半）
- 任意条件: 園地名、処理区（完全一致）
- `計測日`や`月`列から対象月・前後半を再計算しない。
- `調査基準月`は `YYYY-MM` として解釈し、その年を表示年度とする。不正な値は補正せず除外する。

## 表示と状態

1行は登録ID単位であり、同日・同園地のレコードを統合・平均化しない。表示順は年度、計測日、登録日時の降順、登録IDの昇順で安定化する。

通常表示には `正常`、`横径なし`、`糖度なし`、`酸度なし` を含める。`要確認`は `includeNeedsReview` が真のときだけ含め、`取消`と未知の状態は常に除外する。欠測値は `null` を維持し、表示時は `—` とする。

一覧の実装対象列は、計測日、園地名、処理区、備考、横径平均、糖度、酸度、各前回差である。予測値と気象値は後続Issueで実装する。

## 品種カテゴリー

品種文字列は NFKC、前後空白除去、連続空白統一、括弧統一後、完全一致の別名マスタでカテゴリー化する。部分一致は使用しない。未登録品種は正規化後の文字列を独立カテゴリーとし、予測モデルは持たない。

| カテゴリー | 別名 | 予測モデル |
|---|---|---|
| ゆら早生 | ゆら早生、ゆら | ゆら早生 |
| 早生(宮川・興津 等、又は山下紅) | 早生、山下紅、早生(宮川・興津など)、早生(宮川・興津 等、又は山下紅) | 興津早生 |
| 田口 | 田口、田口早生 | 田口早生 |
| 中生(向山など) | 中生、中生(向山など)、向山、向山温州 | 向山温州 |
| 晩生 | 晩生、林、林温州 | 林温州 |
| 丹生系 | 丹生系、丹生、丹生温州 | 丹生温州 |

## 前回差

前回差は今回値から前回値を引く。前回は、同じ表示年度・園地名・標準品種カテゴリー・処理区で、計測日が現在より前の最も近いレコードとする。前回候補は現在の検索期間外も含む同年度の全レコードから探す。同日のレコードは候補外とし、同じ前回日付なら登録日時の新しい順、登録IDの昇順で選ぶ。園地名、今回値、前回値のいずれかが欠測なら `null` とし、さらに古い値は探さない。

## 後続Issue

収穫時予測、気象値、一覧UIでの表示桁・目標値表示を実装する。表示桁は横径・糖度・気象値を小数1桁、酸度を小数2桁とする。計算途中では丸めない。
