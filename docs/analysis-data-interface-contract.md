# Output 調査データ連携契約

| 項目 | 値 |
|---|---|
| 仕様バージョン | 1.0.0 |
| 参照先スプレッドシート | 定期調査データバンク |
| 参照タブ | `調査データ` |
| アクセス | 読取専用 |

## 境界

- Output は `調査データ` タブだけを参照する。
- Output は Google Spreadsheet のいかなるタブ・セルにも書き込まない。
- Output は列番号・行番号に依存せず、見出し名で列を解決する。
- 未知の追加列は無視する。
- `登録ID` をレコードの識別子として扱う。

## 正式な見出し

| 見出し名 | 型 | 欠測値 | Output での扱い |
|---|---|---|---|
| 登録ID | UUID文字列 | 不可 | 主キー |
| 登録日時 | 日付文字列 | 空欄可 | 登録日。Google Sheetsのシリアル数値も日付文字列へ変換する |
| 計測日 | 日付文字列 | 空欄可 | 観測日。Google Sheetsのシリアル数値も日付文字列へ変換する |
| 年度 | 数値文字列 | 不可 | 年度条件 |
| 年 | 数値文字列 | 不可 | 年 |
| 月 | 数値文字列 | 不可 | 月 |
| 調査基準月 | 文字列 | 不可 | 時系列条件 |
| 調査区分 | 文字列 | 不可 | 前半／後半条件 |
| 園地名 | 文字列 | 空欄可 | 園地条件 |
| 品種 | 文字列 | 空欄可 | 品種条件 |
| 処理区 | 文字列 | 空欄可 | 処理区条件 |
| 備考 | 文字列 | 空欄可 | 参照のみ |
| 横径個数 | 数値文字列 | 空欄可 | 横径標本数 |
| 横径平均 | 数値文字列 | 空欄可 | 横径分析・予測の観測値 |
| 横径最小 | 数値文字列 | 空欄可 | 横径分析の補助値 |
| 横径最大 | 数値文字列 | 空欄可 | 横径分析の補助値 |
| 糖度 | 数値文字列 | 空欄可 | 糖度分析・予測の観測値 |
| 酸度 | 数値文字列 | 空欄可 | 酸度分析・予測の観測値 |
| 糖酸比 | 数値文字列 | 空欄可 | 参照・比較値 |
| データ状態 | 文字列 | 不可 | `正常` のレコードを通常集計対象とする |
| 入力方法 | 文字列 | 不可 | 参照のみ |
| 入力者 | 文字列 | 空欄可 | 参照のみ |
| 送信元 | 文字列 | 空欄可 | 参照のみ |

## 値の変換

- 空欄の数値は `0` ではなく `null` に変換する。
- 空欄の園地名・品種・登録日時・計測日も `null` に変換する。
- 日付のシリアル数値はGoogle Sheetsの日付として文字列に変換する。
- `処理区`・`備考`・`入力者`・`送信元` の空欄は `null` に変換する。
- `データ状態` が `正常` 以外のレコードは、通常の分析・予測集計から除外する。
- `横径個数`、`横径平均`、`横径最小`、`横径最大`、`糖度`、`酸度`、`糖酸比` は数値として解釈できない場合、取込エラーとする。

## 正本27列との関係

`調査データ` は Output の分析用読取ビューであり、Input の正本 `調査原票` とは別契約である。
Output は `調査原票`、`過去データ`、`変換済み過去データ`、`入力マスタ`、`解析補正ログ` を参照しない。
