# Output Spreadsheet 連携契約

## Spreadsheet 別のアクセス境界

| Spreadsheet | 対象シート | Output からのアクセス | 位置づけ |
|---|---|---|---|
| Input の正本 Spreadsheet | `調査データ` | 読取専用 | 調査データの唯一の正本 |
| 予測原典 Spreadsheet | `横径予測`、`糖度予測`、`酸度予測` | 読取専用 | 予測係数の原典 |
| Output 専用の正規化予測マスタ | `予測モデルマスタ`、`予測係数マスタ` | 独立 Issue で定義された Writer だけが更新可能 | 検証済み Reader 出力から生成する派生マスタ |

### Input の正本 Spreadsheet

- Input は調査データの唯一の正本である。
- Output が参照できる Input Spreadsheet のタブは `調査データ` だけであり、他のタブは参照しない。
- Output は Input Spreadsheet のいかなるタブ・セルにも書き込まない。
- Output は Input のコード、データ構造、見出しを変更しない。
- 派生値、予測値、AIコメントを Input へ書き戻さない。

### 予測原典 Spreadsheet

- `横径予測`、`糖度予測`、`酸度予測` は読取専用とする。
- 原典シートを変更、削除、補正しない。
- Prediction Master Reader は認証スコープ `https://www.googleapis.com/auth/spreadsheets.readonly` だけを使用する。
- 原典の空白セル、物理位置、係数、数式を変更せずに読み取る。

### Output 専用の正規化予測マスタ

- `予測モデルマスタ` と `予測係数マスタ` は Output 専用の派生マスタであり、Input の正本データではない。
- 検証済みの Prediction Master Reader 出力だけを生成元とする。
- 書込みは、独立した Prediction Master Writer Issue で定義・検証された Writer だけに許可する。
- Writer 以外の UI、分析処理、Prediction Engine から直接更新しない。
- Writer は失敗時に既存マスタを破損させない。
- Google Sheets の書込み権限を含む権限拡大は、Writer Issue の着手時に限定して判断する。

## Input 調査データ連携契約

| 項目 | 値 |
|---|---|
| 仕様バージョン | 1.0.0 |
| 参照先スプレッドシート | Input の正本 Spreadsheet（定期調査データバンク） |
| 参照タブ | `調査データ` |
| アクセス | 読取専用 |

### 境界

- Output は Input の正本 Spreadsheet では `調査データ` タブだけを参照する。
- Output は Input の正本 Spreadsheet のいかなるタブ・セルにも書き込まない。
- Output は列番号・行番号に依存せず、見出し名で列を解決する。
- 未知の追加列は無視する。
- `登録ID` をレコードの識別子として扱う。

### 正式な見出し

| 見出し名 | 型 | 欠測値 | Output での扱い |
|---|---|---|---|
| 登録ID | UUID文字列 | 不可 | 主キー |
| 登録日時 | `YYYY-MM-DD` | 空欄可 | 登録日。取得経路に依存しない有効な暦日へ正規化する |
| 計測日 | `YYYY-MM-DD` | 空欄可 | 観測日。読取時に厳格な暦日へ正規化する |
| 年度 | 数値文字列 | 不可 | 年度条件 |
| 年 | 数値文字列 | 不可 | 年 |
| 月 | 数値文字列 | 不可 | 月 |
| 調査基準月 | 文字列 | 不可 | 時系列条件 |
| 調査区分 | 文字列 | 不可 | 前半／後半条件 |
| 園地名 | 文字列 | 空欄可 | 園地条件 |
| 品種 | 文字列 | 空欄可 | 品種条件 |
| 処理区 | 文字列 | 空欄可 | 処理区条件 |
| 備考 | 文字列 | 空欄可 | 参照のみ |
| 横径個数 | 数値文字列 | 空欄可 | 横径標本数 |
| 横径平均 | 数値文字列 | 空欄可 | 横径分析・予測の観測値 |
| 横径最小 | 数値文字列 | 空欄可 | 横径分析の補助値 |
| 横径最大 | 数値文字列 | 空欄可 | 横径分析の補助値 |
| 糖度 | 数値文字列 | 空欄可 | 糖度分析・予測の観測値 |
| 酸度 | 数値文字列 | 空欄可 | 酸度分析・予測の観測値 |
| 糖酸比 | 数値文字列 | 空欄可 | 参照・比較値 |
| データ状態 | 文字列 | 不可 | 分析対象判定に使用する |
| 入力方法 | 文字列 | 不可 | 参照のみ |
| 入力者 | 文字列 | 空欄可 | 参照のみ |
| 送信元 | 文字列 | 空欄可 | 参照のみ |

### 値の変換

- 空欄の数値は `0` ではなく `null` に変換する。
- 空白文字だけの任意数値は空セルと同じ欠測として `null` に変換し、必須数値では拒否する。
- 空欄の園地名・品種・登録日時・計測日も `null` に変換する。
- `登録日時`は有効な`YYYY-MM-DD`または`null`だけを返す。時刻はMVPの正式DTOに含めず、他列から補完しない。
- 登録日時のGViz `Date(year, zeroBasedMonth, day)`、`YYYY-MM-DD`、`YYYY/MM/DD`は、存在する同一の暦日へ正規化する。
- 登録日時の有限かつ0以上のGoogle Sheetsシリアル値は、基準日`1899-12-30`から整数部だけで暦日を求める。小数部の時刻は暦日契約への射影として使用しない。
- 登録日時の`Z`または明示オフセット付きISO 8601日時は、その瞬間をAsia/Tokyoへ変換して暦日を得る。タイムゾーンなし日時は拒否する。
- `計測日`は有効な`YYYY-MM-DD`または`null`だけを返す。登録日時や年・月から補完しない。
- GVizの`Date(year, zeroBasedMonth, day)`は月を1始まりへ変換し、存在する暦日か検証する。
- `YYYY-MM-DD`と`YYYY/MM/DD`は時刻へ変換せず、入力の暦日を維持する。
- `Z`または明示オフセット付きISO 8601日時はAsia/Tokyoへ変換して暦日を得る。タイムゾーンなし日時は拒否する。
- 日付だけを表す有限整数のGoogle Sheetsシリアル値は`YYYY-MM-DD`へ変換し、非整数値は計測日として拒否する。
- JavaScript Dateによる存在しない日付の繰上げ補正を行わない。
- `処理区`・`備考`・`入力者`・`送信元` の空欄は `null` に変換する。
- 通常の分析対象は `正常`、`横径なし`、`糖度なし`、`酸度なし` とする。欠測値は `null` のまま保持する。
- `要確認` は明示的に指定した場合だけ分析対象とする。取消・削除・未知の状態は常に対象外とする。
- `横径個数`、`横径平均`、`横径最小`、`横径最大`、`糖度`、`酸度`、`糖酸比` は数値として解釈できない場合、取込エラーとする。
- 旧データの小数点欠落に対応するため、`横径平均`、`横径最小`、`横径最大`の正数が`100`以上`1000`未満の場合だけ、Outputの正式DTOで`10`除算する（例：`485`は`48.5`）。Input正本は変更しない。
- この旧横径補正を`横径個数`、糖度、酸度、糖酸比、欠測値へ適用しない。範囲外の値も推測補正しない。

### 現行の認証付き取得境界

- `/analysis`と`/orchards`は、サーバー側の`GoogleSheetsApiAnalysisDataSource`からInput Spreadsheetの`調査データ`だけを取得する。
- Reader用サービスアカウントと`spreadsheets.readonly`スコープだけを使用し、資格情報をブラウザーへ渡さない。
- Spreadsheet ID、正式タイトル、シート名を照合し、Sheets APIではGET以外を使用しない。
- 認証・取得・契約検証の失敗時に、公開GViz経路へ自動フォールバックしない。

### 旧GViz取得境界

- Outputは固定されたInput Spreadsheetとgidに対して、`調査データ`だけをGETで取得する。書込みHTTPメソッドを使用しない。
- `readTab()`は実行時にも`調査データ`以外を拒否し、Repositoryは正式な必須見出しを検証する。
- HTTP失敗、JSON解析失敗、応答構造不正は分類可能なサニタイズ済みエラーとして扱う。
- エラーへSpreadsheet ID、gid、応答本文、登録ID、園地名、個別調査値、認証情報を含めない。
- GViz応答からSpreadsheetタイトルやシートタイトルは取得できないため、タイトル一致を保証しない。固定されたSpreadsheet ID・gid、タブ引数、必須見出しによる多層防御を使用する。
- GViz DataSourceは切替直後のロールバック候補として残すが、画面の通常取得経路からは呼び出さない。
- 匿名Viewer解除とGViz実装の削除は、Cloud Run上の画面回帰完了後に独立Issueで扱う。

### 正本27列との関係

`調査データ` は Output の分析用読取ビューであり、Input の正本 `調査原票` とは別契約である。
Output は `調査原票`、`過去データ`、`変換済み過去データ`、`入力マスタ`、`解析補正ログ` を参照しない。
